# minipixel

This is a basic 'image editor' (in the broad sense of the word) in a static site. In spite (or maybe thanks to) the wonky code, it fits under 3.5kB. With some optimization I am hoping to fit it in a QR code. For "performance" (scare quotes) and catering to nerds who have 7 different anti-fingerprinting extensions, this does not use <canvas>. Instead, all pixels are in a html table <3

## Controls

Click on a color button in the bottom to pick a drawing color, then draw on the drawing area (hold down mouse button of course). Black button with a ↓ exports your aristic masterpiece.
